# Инструкция: конкретные магазины по ID (только браузер, без терминала)

Обновлённая версия проекта: пользователь выбирает **конкретные филиалы** («Магнит на Ленина 45»),
а не просто сети. Код лежит в `/workspace/browser_only/`:

- `pwa/` — фронтенд для StackBlitz (проверен: `tsc --noEmit` и `vite build` проходят)
- `cloud_function/` — бэкенд для Colab / Yandex Cloud (только requests + BeautifulSoup)

---

## Шаг А — StackBlitz (фронтенд)

1. Откройте **stackblitz.com** → войдите через Google → **Create New Project** → шаблон **Vite + React + TS**.
2. Замените/создайте файлы из папки `browser_only/pwa/` (правый клик по папке → New File → вводите путь целиком, например `src/components/Settings.tsx`; ПКМ по файлу → Delete для лишних файлов шаблона `src/App.css`, `src/assets`).
   Обновлены в этой версии: `src/types.ts`, `src/lib/storage.ts`, `src/components/Settings.tsx`, `PriceManager.tsx`, `MenuGenerator.tsx`, `ShoppingList.tsx`. Остальные (package.json, конфиги, recipes.json, App.tsx, index.css) — без изменений.
3. После замены `package.json` подождите 30–60 сек (установка зависимостей). Предпросмотр справа.
4. Данные (настройки с ID магазинов, цены, меню, чекбоксы) сохраняются в IndexedDB браузера.

Что нового в UI:
- **Настройки**: поле «Мой адрес» + кнопка геолокации (браузерный API), для каждой сети — чекбокс + поле «ID моего магазина» + подсказка, где этот ID взять; кнопка «Найти магазины рядом» — пока заглушка (alert).
- **Цены**: «Обновить цены» шлёт `GET {URL функции}/api/prices?stores=magnit:1234,pyaterochka:9876`, сохраняет ответ по каждому филиалу в IndexedDB (ключ `prices:сеть:ID`). Без URL функции — локальные демо-цены.
- **Список покупок**: позиции группируются по конкретным филиалам (сеть + бейдж ID), у каждого магазина своя итоговая сумма + общая сумма и прогресс «уже в корзине».

## Шаг В — Деплой в Yandex Cloud Functions

1. console.yandex.cloud → **Functions** → «Создать функцию».
2. Runtime **Python 3.11**, роль `editor`, триггер **HTTP** (GET), **«Публичный доступ»** ✓.
3. Во встроенном редакторе создайте `main.py`, `requirements.txt` (`requests`, `beautifulsoup4`) и файлы в папке `parsers/`. Энтрипоинт: `main.handler`. «Задеплоить».
4. Проверьте прямо в браузере:
   `https://functions.yandexcloud.net/<id>?stores=magnit:1234,pyaterochka:9876`
5. Скопируйте URL в поле «Источник актуальных цен» в настройках PWA.

## Шаг Г — Как пользователю найти ID своего магазина (словесно, по сайтам)

**Магнит** — magnit.ru:
1. Откройте раздел «Доставка» (magnit.ru/delivery).
2. Вверху страницы нажмите на текущий адрес/магазин — откроется список ближайших точек.
3. Выберите свой магазин (например, «ул. Ленина, 45»).
4. Посмотрите на строку адреса браузера: там появится параметр вида `?shopId=1234` (или цифры после `/shop/`). Это число и есть ID — скопируйте его в поле «ID моего магазина».

**Пятёрочка** — 5ka.ru:
1. Откройте m.5ka.ru, нажмите на город/адрес магазина в шапке.
2. Выберите точку из списка ближайших.
3. ID — числовой хвост в URL страницы каталога (параметр `store=` или сегмент пути). Скопируйте цифры.

**Монетка** — ekamonetka.ru:
1. Раздел «Доставка» / карта магазинов.
2. Кликните по своему магазину на карте — откроется его страница.
3. ID — число в URL этой страницы (например, `/shop/5678/`).

**Мегаполис** — mega-polis.ru:
1. Страница «Адреса» / «Магазины».
2. Найдите свой филиал в списке, откройте его карточку.
3. ID — номер из URL или из заголовка страницы («Магазин №42» → `42`).

Совет: если точный ID найти не удаётся — впишите любой номер филиала из URL соседней страницы того же города: парсер всё равно вернёт fallback-демо, и приложение продолжит работать до подключения реальных эндпоинтов.
